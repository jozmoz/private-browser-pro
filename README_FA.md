**Private Browser Pro** یک نرم‌افزار دسکتاپ مدرن و سبک است که به شما امکان می‌دهد پروفایل‌های مرورگر کاملاً مجزا با هویت دیجیتال اختصاصی (شبیه‌سازی کارت گرافیک، بوم، صدا، مشخصات سخت‌افزاری)، حالت‌های وبگردی موقت و بدون ردپا (Zero-Data)، و تونل پروکسی اختصاصی با محافظت در برابر نشت DNS ایجاد و مدیریت کنید.

## 🌟 قابلیت‌های کلیدی

### ۱. 🛡️ جعل پیشرفته اثرانگشت و مشخصات سخت‌افزاری
- **شبیه‌سازی دقیق WebGL و کارت گرافیک:** پشتیبانی از پروفایل‌های واقعی کارت‌های گرافیک NVIDIA (سری‌های RTX 4090, 4080, 4070, 3080)، AMD Radeon (سری RX 7900 XTX, 6700 XT)، گرافیک‌های Intel Arc و تراشه‌های Apple Silicon.
- **تزریق نویز به بوم (Canvas) و صدا (AudioContext):** تزریق نویز نامحسوس برای جلوگیری از ردیابی هش اثرانگشت توسط وب‌سایت‌ها و ترکرها.
- **همگام‌سازی داینامیک Client Hints:** نسخه برند کرومیوم در `navigator.userAgentData` به صورت خودکار با User-Agent مطابقت پیدا می‌کند تا سایت‌های ضدبات به مرورگر مشکوک نشوند.
- **ماسک کردن Webdriver:** متغیر `navigator.webdriver` به صورت پیش‌فرض مقدار `undefined` دارد و توابع با شبیه‌سازی کدهای نیتیو محافظت می‌شوند.
- **سازگاری کامل با کلودفلر و کپچا:** تنظیم‌شده جهت عبور طبیعی از چالش‌های Cloudflare Turnstile، hCaptcha و reCAPTCHA.

### ۲. 🔒 ایزولاسیون داده‌ها و حالت یک‌بار مصرف (Zero-Data)
- **💾 حالت پایدار (Persistent Storage):** ذخیره امن تاریخچه، نشست‌ها و کوکی‌ها در پوشه ایزوله اختصاصی همان پروفایل.
- **⚡ حالت موقت و یک‌بار مصرف (Ephemeral):** راه‌اندازی نشست‌های کاملاً ایزوله که پس از بستن پنجره مرورگر، بدون باقی ماندن هیچ ردپایی به طور کامل از دیسک پاک می‌شوند.
- **🧹 پاک‌سازی با یک کلیک:** امکان پاکسازی نشست‌ها یا حذف کامل پوشه‌های موقت در هر زمان.

### ۳. 🌐 پل ارتباطی پروکسی (Proxy Bridge) و ضد نشت DNS
- **پل محلی شفاف:** پشتیبانی کامل از پروتکل‌های HTTP و SOCKS5 به همراه نام کاربری و کلمه عبور.
- **رزولوشن DNS روی سرور پروکسی:** ارسال درخواست‌های DNS از طریق خود پروکسی جهت جلوگیری قطعی از نشت DNS.
- **محافظت از نشت IP در WebRTC:** مسدودسازی اتصالات UDP بدون پراکسی برای جلوگیری از فاش شدن IP واقعی در تماس‌های صوتی و تصویری وب.

### ۴. ⚡ موتور کرومیوم رسمی کاربری
- **نسخه رسمی کاربران عادی:** مبتنی بر بیلد استاندارد و پرتابل **Ungoogled Chromium** (نسخه ۱۵۱).
- **بدون هرگونه بنر تستی:** فاقد علائم Chrome for Testing، اخطارهای فلگ‌های خط فرمان و هشدارهای API گوگل.
- **صفحه شروع مدرن و دارک:** تب جدید اختصاصی همراه با دسترسی سریع به سایت‌های پرکاربرد (Google, YouTube, GitHub, Telegram, ChatGPT) و نمایش زنده مشخصات سیستم.

### ۵. 🌍 رابط کاربری دوزبانه (انگلیسی و فارسی)
- زبان پیش‌فرض انگلیسی با قابلیت سوییچ فوری به زبان فارسی (با جهت‌بندی راست‌به‌چپ و فونت خوانا).
- پشتیبانی کامل بین‌المللی در تمامی پنجره‌ها، فرم‌ها و پیام‌های سیستم.

## 🚀 راهنمای راه‌اندازی و اجرا

### پیش‌نیازها
- نصب بودن [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر پیشنهاد می‌شود)
- ویندوز ۱۰ یا ۱۱ (نسخه ۶۴ بیتی)

### مراحل نصب

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/your-username/private-browser-pro.git
   cd private-browser-pro
   ```

۲. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

۳. **اجرای برنامه:**
   ```bash
   npm start
   ```

> **نکته:** در اولین اجرا در صورت موجود نبودن کرومیوم، می‌توانید با کلیک روی دکمه دانلود در هدر برنامه، نسخه پرتابل را مستقیماً دریافت و آماده استفاده نمایید.
